# AOW App

A modern React-based order management app for restaurants, featuring intuitive UI for collecting and summarizing customer orders.

## Features

- Multi-person order collection
- Customizable sandwich options (salad, tahina)
- Real-time order summaries
- Kitchen-ready grouped output
- Responsive design

## Tech Stack

- React 19
- Vite
- CSS-in-JS styling

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Build for production: `npm run build`
